# STRIKE_RA
STRIKE RA is an AI-powered threat-led security risk assessment that replaces complex spreadsheets with a guided conversation and produces defensible, evidence-driven outputs in minutes.

## The STRIKE methodology

| Step | Name | Question |
|------|------|----------|
| **S** | Scope | Tell me about your project. |
| **T** | Threat | What could attack it? |
| **R** | Route | How would they succeed? |
| **I** | Impact | What would happen? |
| **K** | Keep Operating | How do we keep operating? |
| **E** | Execute | Generate outputs. |

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Then open http://localhost:5000 in your browser.
